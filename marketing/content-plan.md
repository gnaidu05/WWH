# The Agency — 2-Week Launch Content Calendar

**Product:** The Agency — an open-source library of 85 handwritten AI specialist agents, installable into your AI coding tool with one command. MIT licensed, free.
**Landing page:** https://gnaidu05.github.io/WWH/
**Repo:** https://github.com/gnaidu05/WWH
**Primary audience:** developers, indie hackers, AI builders, and technical founders who already use an AI coding tool (Claude Code, Cursor, Copilot, Codex, Gemini, Windsurf, Aider).
**Overarching goal:** GitHub stars + installs, driven by the "generic prompt vs. pinned-down specialist" story and the orchestrator payoff.

## Voice reminder for every writer
Confident, technical, dry wit welcome. No hype-bro clichés, no fabricated metrics, no "revolutionary." The product's own line is **"a starting point you own."** Honesty rule: it is **85 agents, not 232** — and the message is *"don't install all 85, start with these 7."*

## Repurposing map

**Pillar asset:** the hero announcement (`assets/launch-announcement.md`).

Derivatives it feeds:
- **X thread** — the generic-vs-specialist argument, cut into native beats + orchestrator payoff.
- **LinkedIn post** — the same story, reframed for founders and reshaped for a professional feed.
- **HN / Reddit posts** — the honest, plain-text version that survives skeptical technical readers.
- **Newsletter (Day +3)** — the "why we handwrote them" section, expanded.
- **Single-agent spotlights** (Days +2, +8) — one section of the announcement (the deliverable contract) per agent.
- **Division carousel (Day +5)** — the 16-divisions paragraph, made visual.

## Measurement
- **Primary metric:** GitHub stars + clones/installs (repo insights).
- **Secondary:** landing-page visits, thread reposts/saves, HN/Reddit upvotes and comment sentiment.
- **Guardrail:** every post names its audience, funnel stage, and CTA before it ships. No filler posts to "stay active."
- **Fact-check:** all product claims verified against PRODUCT FACTS before publish (route through `reality-checker`). It is 85 agents. It is free and MIT. No invented stars, users, or testimonials.
